# CineTrack

O CineTrack é um catálogo de filmes, com cadastro, listagem, busca e filtros.

## Como rodar o backend

Acesse a pasta backend pelo terminal e rode o comando "npm run dev".

## Como rodar o frontend

Acesse a pasta frontend pelo terminal, rode o comando "npm run dev", então acesse http://localhost:5173.
